# Demo Video Script

Target duration: 3–5 minutes.

## 1. Introduction
Explain that the product is designed for an HR Manager managing compensation data for 10,000 employees.

## 2. Salary Insights
Show average, minimum and maximum salary and department filtering. Mention that analytics are calculated by backend database aggregation.

## 3. Employee List
Show 10,000 employee count, search, pagination and column sorting. Explain that the browser does not load all 10,000 records.

## 4. Salary Operations
Demonstrate individual adjustment, absolute salary update, employee selection and bulk adjustment.

## 5. CRUD
Demonstrate Add, Edit and Delete with confirmation.

## 6. Engineering
Briefly show the repository, tests, architecture and incremental commits. Mention intentional AI-assisted development and validation.

## Closing
Explain that the solution keeps the architecture simple while using server-side operations and clear boundaries to handle the 10,000-employee requirement.
